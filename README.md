# Новости – податоци за mad.org.mk

Податоци за веб-страницата на Македонското археолошко друштво (https://mad.org.mk).

- `news.json` – археолошки вести; се дополнува секое утро (околу 06:50) со автоматско собирање.
- `bib-new.json` – нова библиографија; се дополнува на 1-ви во месецот.

Секој час во :20 (на пр. 07:20) серверот на mad.org.mk ги презема двете датотеки од тука,
ги проверува дека се исправен JSON и ги заменува старите на страницата.

Не менувајте ги рачно без потреба – грешка во JSON не се пренесува на страницата,
но вестите тогаш нема да се освежат.
